TL15 UI SYSTEM

목적
- 기존 기능 및 데이터 구조 유지
- 전체 화면 폭, 좌우 여백, 헤더, 카드, 버튼, 하단 메뉴 규격 통일

공통 기준
- 모바일 최대 폭: 430px
- 기본 좌우 여백: 16px
- 공통 헤더 최소 높이: 58px
- 공통 하단 메뉴 높이: 72px
- 카드 기본 라운드: 22px
- 주요 터치 영역 최소 높이: 48px

적용 화면
- HOME
- FARM
- WALK
- REWARDS
- RANKING
- INVITE
- CROP SELECT

주의
- 이번 버전은 기능 변경이나 최종 일러스트 교체가 아닌 1차 UI 규격 통일 버전입니다.
- 화면별 최종 픽셀 조정과 공식 이미지 교체는 후속 패치에서 진행합니다.
