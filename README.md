# TTOK LIFE V1

압축을 풀고 Windows에서 아래 순서로 실행하세요.

1. `1_INSTALL.bat` 더블클릭
2. 설치 완료 후 `2_RUN.bat` 더블클릭
3. 브라우저에서 `http://localhost:3000` 접속

## Node.js

Node.js 20 이상이 필요합니다. 설치되어 있지 않으면 `1_INSTALL.bat`가 안내합니다.

## 직접 명령어로 실행

```bash
npm install
npm run dev
```

## 포함 기능

- 여자 캐릭터 2명: 하니, 하린
- 남자 캐릭터 2명: 하준, 민준
- 캐릭터 선택 → 닉네임 → 동네 → 게임 시작
- 홈, 농장, 산책, 우리 동네 걷기왕, 보상함, 주민 초대, 내 정보
- 걸음·칼로리·물방울·경험치 상태
- 작물 성장, 수확, 실제 상품 보상함
- 브라우저 localStorage 저장
- 모바일 게임형 UI

## 중요

현재 산책 화면의 걸음 증가는 UI와 상태 흐름 확인용입니다.
이미 검증한 V0.3 실제 센서 만보기 엔진은 다음 버전에서 연결합니다.


## Windows 글자 깨짐 수정본

배치 파일은 Windows CMD 문자 인코딩 문제를 피하기 위해 영문 파일명과 영문 메시지만 사용합니다.

1. `1_INSTALL.bat`
2. `2_RUN.bat`
3. 필요할 때 `3_CHECK.bat`


## V1.1 변경 사항

- 승인된 첫 번째 메인 시안을 실제 접속 홈 화면으로 적용
- 메인 시안 전체를 고해상도 게임 보드로 사용
- 시안 속 농장·산책·걷기왕·보상함·하단 메뉴 영역을 실제 버튼으로 연결
- 물방울과 레벨은 게임 상태의 실시간 값으로 화면 위에 표시
- 나머지 페이지와 기존 게임 상태 기능은 그대로 유지

현재 V1.1의 목표는 **메인 홈의 시안 일치도 확인**입니다.
다음 버전부터 농장 → 산책 → 걷기왕 → 보상함 순으로 같은 퀄리티를 적용합니다.


## 화면이 이전 버전으로 보일 때

기존 V1 개발 서버가 `localhost:3000`에서 계속 실행 중일 수 있습니다.

이번 수정본은 충돌 방지를 위해 별도 포트인 아래 주소를 사용합니다.

- 메인 홈: `http://localhost:3011/home`
- 버전 확인: `http://localhost:3011/version`

실행은 `2_RUN.bat`을 사용하세요.
그래도 이전 화면이 보이면 `2_CLEAN_RUN.bat`을 실행하면 기존 Node.js 개발 서버를 종료한 뒤 새 프로젝트를 시작합니다.

첫 번째 시안은 **홈 화면**입니다. 농장 메뉴를 누르면 기존 농장 화면으로 이동하는 것이 정상입니다.


## ROLLBACK 안내

이 버전은 V1.2 농장 시안 적용 전의 안정 버전으로 되돌린 파일입니다.

- 메인 홈 시안 유지
- 농장 화면은 기존 기본 화면으로 복구
- 산책 화면도 기존 기본 화면
- 포트: 3014


## V1.2 농장 — 새 방식

- 시안 전체를 잘라 붙이지 않음
- 농장 일러스트만 이미지 리소스로 사용
- 제목, 물방울, 성장률, 진행바, 버튼, 하단 메뉴는 모두 React/CSS
- 모바일 세로 화면과 PC 미리보기 모두 대응
- 화면 높이가 짧은 기기용 반응형 규칙 포함
- 모바일 테스트를 위해 개발 서버를 `0.0.0.0:3018`로 실행
- `MOBILE_TEST_ADDRESS.bat`에서 PC IPv4 주소 확인 가능


## 화면이 비어 있던 원인과 수정

새 포트로 실행할 때 브라우저 저장소가 새로 만들어져
`onboardingComplete=false` 상태로 `/farm`을 직접 열면 Guard가 화면을 숨겼습니다.

수정 내용:
- 미리보기 버전은 온보딩 완료 상태로 바로 실행
- 이전 저장 데이터와 충돌하지 않도록 새 저장 키 사용
- 로딩 중에도 빈 화면 대신 안내 문구 표시
- 서버가 켜진 뒤 6초 후 브라우저 실행
- 고정 포트 3020 사용

확인:
- 농장: http://localhost:3020/farm
- 버전: http://localhost:3020/version
